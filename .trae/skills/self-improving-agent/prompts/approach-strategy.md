# Approach Strategy Prompt

Use this prompt to develop and refine strategies for task completion.

## When to Use

- Before starting significant tasks
- When choosing between multiple approaches
- When improving existing workflows
- After reflecting on past performance

## Strategy Development Process

### 1. Situation Assessment

Understand the current state:
- What is the current problem or goal?
- What has been tried before?
- What worked and what didn't?
- What constraints exist?

### 2. Option Generation

Explore possible approaches:
- What different ways could we solve this?
- What are the trade-offs of each approach?
- What resources do we have available?
- What risks does each option carry?

### 3. Strategy Selection

Choose the best approach:
- Which option best balances speed, quality, and risk?
- What is our confidence level in this approach?
- What backup plans should we have?
- How will we measure success?

### 4. Execution Planning

Plan the implementation:
- What steps do we need to take?
- In what order should we do them?
- What checkpoints should we include?
- How will we handle problems that arise?

## Common Strategy Patterns

### Incremental Development
- Start with a minimal viable solution
- Add features incrementally
- Test and validate at each step
- Adapt based on feedback

### Divide and Conquer
- Split large tasks into smaller pieces
- Solve each piece independently
- Integrate the solutions
- Verify the whole works together

### Prototype and Iterate
- Create a quick prototype
- Gather feedback
- Refine and improve
- Repeat until satisfied

### First Principles Thinking
- Break down to fundamental truths
- Rebuild solution from ground up
- Challenge assumptions
- Innovate beyond conventional approaches

## Strategy Evaluation

### Questions to Ask

1. Is this strategy achievable with available resources?
2. What's the probability of success?
3. What happens if this approach fails?
4. How long will this take?
5. What are the dependencies?

## Best Practices

1. Always have a backup plan
2. Start with simple, proven approaches before trying complex ones
3. Build in checkpoints and validation points
4. Stay flexible - be ready to pivot if needed
5. Document your strategy and reasoning
6. Review and update strategies based on outcomes
